바이브코딩(Vibe Coding)이란?

기존 코딩: C#, C++, 파이썬, 자바 등 프로그래밍 언어를 직접 작성
바이브코딩: 자연어(한국어)로 원하는 것을 설명하면, AI가 코드로 변환하여 결과물을 만들어주는 방식

끝내주는 기획만 있다면
당신도 끝내주는 개발자!

개발자가 아니어도 됩니다. 중요한 건 아이디어입니다.

일반 클로드 vs 클로드 코드

일반 Claude / GPT
텍스트, 이미지, PDF 전달
리서치 / 문자 전달 / 이미지 생성
Claude Code
폴더 공유 → 프로젝트를 스스로 서치
결과물을 폴더에 직접 생성 + 바이브코딩

생성 가능: 워드, 엑셀, PDF, HTML, PPT, 데이터 기반 그래프 이미지(PNG, JPG)
불가능: 생성형 이미지, 영상
